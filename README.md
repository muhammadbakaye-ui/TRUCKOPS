# TruckOps desktop app

This repository hosts the **TruckOps desktop app releases** only.

- **Download for Windows:** [TruckOps-Setup.exe](https://github.com/muhammadbakaye-ui/TRUCKOPS/releases/latest/download/TruckOps-Setup.exe) (always the latest version)
